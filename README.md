# darken

a browser extension that generates dark color schemes for websites, reducing eye strain during night browsing.

## what is this?

a browser extension that generates dark color schemes for websites, reducing eye strain during night browsing.

this is a fork of [darkreader/darkreader](https://github.com/darkreader/darkreader) with a redesigned ui.

## original vs. this version

this is a fork of the [darkreader/darkreader](https://github.com/darkreader/darkreader) project.

### changes from original

- redesigned the ui with a dark pkm aesthetic. all text is now lowercase. extension renamed from dark reader to darken. auto-update checking added.

## installation

download the `.xpi` file from releases and open it in firefox, or load it temporarily via `about:debugging` > this firefox > load temporary add-on.
