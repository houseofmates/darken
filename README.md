# darken

a browser extension that generates dark color schemes for websites, reducing eye strain during night browsing.

## what is this?

a browser extension that generates dark color schemes for websites, reducing eye strain during night browsing.

this is a fork of [darken/darken](https://github.com/darken/darken) with a redesigned ui.

## original vs. this version

this is a fork of the [darken/darken](https://github.com/darken/darken) project.

### changes from original

- redesigned the ui with a dark pkm aesthetic. all text is now lowercase. extension renamed from darken to darken. auto-update checking added.

## installation

download the `.xpi` file from releases and open it in firefox, or load it temporarily via `about:debugging` > this firefox > load temporary add-on.
